  • The day before: check the PAT expiry date at the top of RUNBOOK.md and rotate the token if the demo is on or after the day before it. Run the RUNBOOK venue-network checklist: make warm from the venue network or the phone hotspot must end with "make warm: OK". Freeze the data: no make data, make load or make export from then on.
  • Half an hour before: from the repo root, make warm. It checks Snowflake auth first (auth or network errors are printed verbatim), resumes the engine, starts the warm query server and runs every hero query twice. It must end with "make warm: OK". The "ready" times it prints are what each act will take. Open the explorer on Overview and this script: open artifacts/deal_graph_explorer.html artifacts/demo_script.html. Do Not Disturb on, chat and mail closed, power connected, a large terminal font.
  • A quarter of an hour before: pre-launch the live session, cd demo_workspace && claude, accept the folder-trust and plugin prompts, and run one throwaway prompt (Run uv run python ask.py --list). Keep that session open. Keep a second terminal in demo_workspace/ for the fallback commands.
  • Ten minutes before: make warm again, because the engine suspends after half an hour idle. Then start make keepalive in its own terminal and leave it running until the Q&A ends. Type /clear in the live session.

Follow-ups come from demo_workspace/query_bank.md (SHOWCASE); keep it open beside this page. Paste prompts from this page with Copy; do not retype.     Right, and the model knew a banker was engaged months before a teaser would reach you. The value is position: who on our team knows that banker (the warm-path act) and whether we are on their call list (the deal-flow act).

    "Grata would have found {{ q_path.targets[status=cold][0].company_name }}."

    Grata finds companies. It does not rank them by readiness and access with evidence, or check them against your portfolio.

    "Where does debt maturity come from on a founder-owned company?"
