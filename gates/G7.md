## Method

- Final assistant text: the `result` event text, or the last assistant text block if there is none. Exact-string match, so tool output is never scanned.
- RAI skill: a `Skill` tool_use whose name contains "rai". Tier-2 ad-libs run in a forked Tier-1 session that already loaded the skill, so they do not require a fresh Skill call. The Finale runs fresh and does require one.
- Names: golden `rehearsal.must_appear` and `must_not_appear` from `data/golden/expected.json`. Tier-2 checks are row-based from `prompts.md` "Expected". The "strict" column also adds `must_not_contain`.
- Latency: last minus first event timestamp. `result.duration_ms` is shown as a cross-check, and the two agree within about 3 s.

Command: `python3 scripts/gate_g7_check.py`. Full output is at the end of this file.

## Tier-1 evaluation: runs 1-3 vs runs 4-6

**View A, all 6 runs.** Strictly, 3 of 3 fails for FLOW (5/6) and CONFLICT (5/6).

**View B, clean runs 4-6.** All four acts pass 3/3, every run loaded `rai-querying`, and all medians are 66.8 s or less (max 66.8, PATH).

**Legitimacy check of the run 1-3 failures.** I read the transcripts for the two failed runs, FLOW run2 and CONFLICT run2.
- Both had `SnowflakeTableObjectsException` from the in-process live path, then `Exit code 3`.
- The fallback `--from-exports` then failed with `no precomputed exports ... (meta.json missing)`.
- Claude correctly refused to invent rows, which is correct behavior and the right outcome for the checker.
- Timing fits R17's cause: `pe_deal_graph/export.py` was last modified 12:37:26, the failures are at about 10:39Z (12:39 local), and `make export` was running.
- Two conditions made it fail, and neither exists on stage. First, an export or edit runs on the same engine and changes the server fingerprint. Second, `exports/` was missing. `exports/` now exists (8 files, including `meta.json`), so the `--from-exports` fallback would have answered.
- Content failures: none. Every run 1-3 pass had all names and no decoy. The slow runs (PATH run2 156.6 s, CONFLICT run3 142.8 s) are the same period, with queuing on a stale server.

Conclusion: the failures are explained by environment contention that cannot occur on stage, so I accept runs 4-6 for Tier-1. Because the all-6 view is not clean, the verdict carries a note.

NOTE (condition for the accepted view): the stage setup must keep the warm query server up and `exports/` present. The demo path must not run `make export` or edit `pe_deal_graph/` during the demo.
