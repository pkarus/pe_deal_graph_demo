## Decisions and assumptions

- I disabled the raiconfig `deployment:` section. In relationalai 1.27.1, any `deployment:` block sets `Config.deployment_enabled`. With `auto_deploy` unset, every query compiles against tables that `rai models deploy` would have created. The first smoke run failed on missing `DEAL_GRAPH.SMOKEROW`. The package moved `model.schema` to `deployment.schema`, so the rai-setup skill's `model: schema:` example is stale. The package wins.
- I accepted the bootstrap as applied, with a deviation: `GRANT ROLE RAI_DEMO_PE TO USER` is absent and the role is owned by ACCOUNTADMIN. The required grants match, and access works through ACCOUNTADMIN > SYSADMIN > RAI_DEMO_PE.
- I used the non-deprecated `rai reasoners create ... --auto-suspend-mins 30 --wait`. The colon form is deprecated in 1.27.1.
- The smoke table is never replaced, so its data stream stays valid.
