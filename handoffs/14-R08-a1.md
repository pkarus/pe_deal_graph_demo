## Decisions and assumptions

- **Contract in code.** Every derived name R09 and R10 produce is declared in core.py. rules.py and graphs.py import only core and add `model.define(...)` rules, so there is no import cycle, even though graph outputs feed rules and rules feed graphs. R11 can query the names now. **Never redeclare a contract name** (the model is append-only). Change core.py and ONTOLOGY.md together; the check fails on drift (name or type).
- **Organizations.** Organization has one shared `id` space. Polymorphic `org_id` resolves via `Organization.filter_by(id=...)`, and the `org_type` columns are not mapped.
- **Tables mapped as relationships.** COMPANY_SITE becomes `Company.operates_in(Region)`. COMMERCIAL_LINK becomes the concept CommercialLink plus the direct relationship `Company.supplies(Company)`.
- **Finale fields.** The finale has its own fields (`warm_path_points`, `finale_score`, `finale_tier`, `finale_rank`, `has_conflict`). A_WARM_PATH is not a ScoreComponent, so Act-1 scores cannot change when the FINALE flag is on.
- **ConflictSubject** = the PipelineEntry with stage "IOI prep" (only Tessmark).
- **BuyingFund** = the Northwind fund with the latest vintage (Fund IV, F517). Its EBITDA band and its `area_guideline_pct` (35) drive eligibility and concentration.
- **Units.** Percentages are 0-100 Floats and money is USD millions.

## Known issues

- MINOR (fixed): the first engine run showed `Sector.parent`, `Region.parent` and `Company.supplies` with 0 facts. Two `Concept.filter_by` calls on the same concept in one rule collapse into one variable. They are now bound with two `.ref()`s, and the check asserts there are no self-pairs. R09 and R10 must use refs for any same-type join.
- MINOR: R07 reloads with CREATE OR REPLACE, so the RAI streams for this model must re-sync after every reload. The first query after a reload can take 1.5-2.5 min. If a reload happens mid-run, SQL and RAI counts can disagree transiently: my first run saw INTERMEDIARY = 0 in SQL while R07 was loading. Re-run the check after the load finishes.
- INFO: R07's handoff text lists TRANSACTION_PARTY as 291 rows, but MANIFEST.json and the loaded table both have 283, and the check passed at 283. The check compares against live Snowflake counts, so it stays valid after any reload, including P5 noise.
- INFO: `filter_by` prints a DeprecationWarning (in favor of `lookup`). It works on 1.27.1. `lookup` is unverified on the engine, so I kept `filter_by`.
