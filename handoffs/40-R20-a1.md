## Root cause of R13's error
`Q-PATH: no DecisionMaker rows for the targets q_path() returned` had two causes:
- **Engine contention.** Other processes share the engine and push different rule sets to the same model; for example, `ask.py serve` does not enable the finale rules. While that happens, queries can return empty frames. My run 4 saw `finale_rescore()` come back empty four times in a row while `ask.py serve` and the rehearsal were active. Run 5, a few minutes later, was clean.
- **Fragile join.** export.py joined q_path's targets to DecisionMaker by display name.

The dm_hops/commercial_hops field-order change does not affect export.py. It reads `DecisionMaker.hops` and the `q_*` frames, never `Person.dm_hops` or `Company.commercial_hops` (grep confirmed).

## What I changed
All changes are in `pe_deal_graph/export.py`.
- **Q-PATH target selection.** Targets now come from q_path()'s `company_id` column, with a name match only as a fallback.
  - An empty q_path frame is a clear error.
  - A mismatch prints both id sets.
- **Hero call retries (`with_retry`).** Each hero call is retried up to 3 times, 60 s apart, on:
  - a lock, 503, upstream connect error or SUSPENDING engine;
  - GraphOutputMissing;
  - a KeyError (an empty frame inside q_score/finale);
  - an empty hero frame.
- **Model read retries.** Every `Live.df` read retries on the same transient errors.
- **Empty-read guard.** `Live.prop` and `Live.flag` now re-read an empty result:
  - Required reads (`REQUIRED_READS`: has_conflict, in_crm, score, tier, finale_* and others) retry 3 x 60 s, then fail.
  - Other reads re-read once after 15 s, then accept the empty result with a warning.
  - Why: one run (run 3) read has_conflict as empty and put Tessmark into the finale Tier A rows. Only the decoy assertion caught it.
- **Per-question decoy assertion.** `assert_no_decoys` now follows the same semantics as tests/test_hero.py. For each question, the golden must_not_contain ids must be absent from the answer set, and the golden rehearsal must_not_appear / tier1_must_not_appear names must be absent from the answer text. The answer sets are:
  - Q-SCORE: Tier A rows. The Tier A/B row text is also checked for must_not_appear names.
  - FINALE: Tier A rows.
  - Q-PATH: targets, decision-makers and warm-path nodes/orgs.
  - Q-FLOW: the betweenness top 5 and the coverage gaps.
  - Q-CONFLICT: exposures.
  - A negative test (Brayford injected into the top 5, Redfern into exposures, Tom Harlowe into a path summary) is caught.
- **Graph coverage.** Every q_score row (Tier A and B) is now a forced hero node in graph.json. Five Tier B companies had fallen outside the 600-node subgraph, which violates the contract.
- DECISIONS.md: 7 R20 lines.
